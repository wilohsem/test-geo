DISTINTEC GEO v5.4 - Actualización estética

Cambios:
- Encabezado superior cambiado de azul a naranja.
- Se incorporan los logos Gorila y Difemat.
- Encabezado y logotipos adaptables a pantallas móviles.
- Se mantienen las funciones y categorías de la versión 5.3.

Actualización en GitHub:
1. Descomprime el ZIP.
2. En GitHub abre el repositorio test-geo.
3. Selecciona Add file > Upload files.
4. Sube y reemplaza index.html, logo-gorila.png y logo-difemat.webp.
5. Confirma con Commit changes.
6. Espera la actualización de GitHub Pages y recarga la aplicación.

Importante: los dos logotipos deben quedar en la raíz del repositorio, al mismo nivel que index.html.
