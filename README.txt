DISTINTEC GEO v5.3 - Tres categorías comerciales

El selector Tipo de establecimiento y el formulario Registrar establecimiento muestran únicamente:
1. Ferretería
2. Distribuidores industriales
3. Materiales de construcción

Clasificación automática OSM:
- Ferretería: etiquetas hardware, doityourself, tools, paint, electrical, plumbing, locksmith y nombres explícitos.
- Materiales de construcción: building_materials, tiles, flooring, bathroom_furnishing, timber, lumber, aserraderos y nombres explícitos.
- Distribuidores industriales: industrial_supply, wholesale, maquinaria, equipos, seguridad industrial, suministros y etiquetas industriales.
- Los elementos que no coinciden con las tres categorías quedan como "Otros establecimientos" y no aparecen al filtrar una de las tres categorías.

Actualización en GitHub:
1. Descomprime este ZIP.
2. Abre index.html y copia todo su contenido.
3. En GitHub abre el repositorio test-geo, luego index.html y el lápiz Edit.
4. Reemplaza el contenido y presiona Commit changes.
5. Espera la publicación de GitHub Pages y recarga la página.

Nota:
La clasificación depende de las etiquetas y nombres disponibles en OpenStreetMap. Algunos establecimientos pueden estar incompletos o mal etiquetados.
